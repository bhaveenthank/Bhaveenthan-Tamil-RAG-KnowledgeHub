# Knowledge Layer Roadmap

## Phase 22: Entity Registry Population

Curate deity, person, place, natural-object, and concept identities. Define evidence
annotations and review workflow using a small allowlisted corpus sample.

## Phase 23: Synonym Registry Population

Build versioned literary concept groups with source authority, variants, ambiguity notes,
and human review. Evaluate synonym-expanded recall without treating epithets as synonyms.

## Phase 24: Motif Registry Population

Define a small motif taxonomy, annotation guidelines, positive and negative examples, and
agreement measures for recurring imagery and narrative patterns.

## Phase 25: Literary Device Extraction

Create evidence-bearing epithet, simile, metaphor, allusion, and personification
annotations. Compare deterministic rules and reviewed model-assisted candidates without
publishing unverified classifications.

## Phase 26: Aggregation Engine

Implement exhaustive, field-aware occurrence counting and grouping by author, work,
deity, place, motif, theme, and device. Return evidence sets and corpus-coverage metadata.

## Phase 27: Analytical Retrieval

Combine query resolution, registries, annotations, aggregation, hybrid retrieval, and
citation packaging. Benchmark list recall, count correctness, ranking, and source
traceability before answer generation.

## Gate Between Phases

Each phase requires deterministic artifacts, schema validation, Tamil-focused manual QA,
source citations, explicit corpus scope, and no mutation of frozen releases.
