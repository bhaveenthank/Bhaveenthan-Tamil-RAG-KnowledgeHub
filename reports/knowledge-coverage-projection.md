# Knowledge Coverage Projection

## Purpose

This projection estimates how extraction targets may improve analytical coverage. The
numbers are planning estimates, not benchmark results or promises.

## Current State

- Curated registries exist.
- Query expansion exists.
- Occurrence search exists.
- Aggregation and analytical retrieval exist.
- Comprehensive benchmark exists.
- Literary extraction has not started.

## Projection

| Milestone | Expected Coverage Effect | Estimated Readiness Range |
| --- | --- | ---: |
| Current framework only | Schemas and placeholders clarify target work. | 43-47 |
| Entity/deity pilot | Better alias grounding and devotional analytics. | 48-55 |
| Author/work normalization | Stronger author comparison and cross-work grouping. | 52-58 |
| Epithet pilot | Deity mentions through descriptive names become measurable. | 58-64 |
| Simile pilot | Literary-device questions become partially answerable. | 62-68 |
| Motif/theme pilot | Imagery and theme analytics improve. | 66-72 |
| Relationship graph pilot | Cross-target analytical questions become structured. | 72-78 |

## Main Risks

- Classical Tamil phrasing can make surface matching brittle.
- Literary interpretation may require expert review.
- Device extraction can confuse literal and figurative usage.
- Relationship extraction depends on accepted lower-level candidates.

## Recommendation

Use a small, reviewed fixture set before building automatic extraction. Re-run the
comprehensive benchmark after each accepted knowledge-population milestone.
