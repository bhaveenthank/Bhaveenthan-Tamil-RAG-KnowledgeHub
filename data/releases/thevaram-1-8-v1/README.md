# Thevaram 1-8 Resource Package

This folder documents the current public GitHub resource for Thevaram books 1-8.
It is intended for JCDL review and reuse through the repository.

The main normalized tables are stored in:

`data/processed/thevaram_normalized/`

The stricter audited subset is stored in:

`data/releases/irandaam-thirumurai-v1/`

This package is not a Zenodo deposit. A DOI can be created later after the final
rights/access decision is confirmed.
