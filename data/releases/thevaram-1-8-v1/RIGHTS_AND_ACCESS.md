# Rights And Access: Thevaram 1-8 Corpus Resource

This repository is a research resource built from Tamil Virtual Academy/TamilVU
source pages. It is not an official TamilVU mirror or publication.

otherwise.

## TamilVU-Derived Text

The source literary text and commentary are attributed to Tamil Virtual
Academy/TamilVU. The project did not find a clear open-content redistribution
license for TamilVU-derived full text during repository preparation.

Users should check TamilVU's current terms and applicable copyright law before
redistributing source-derived full text outside normal scholarly review and
research use.
