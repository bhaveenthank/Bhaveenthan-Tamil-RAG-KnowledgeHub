# Rights And Access Statement

## What This Release Contains

This release contains structured corpus records, schemas, audit reports,
checksums, and documentation for an Irandaam Thirumurai corpus derived from
Tamil Virtual Academy/TamilVU source pages.

## Source Attribution

Source pages are attributed to:

Tamil Virtual Academy / TamilVU  
`https://www.tamilvu.org/`

The release preserves source provenance through `hymn_url`, `commentary_url`,
and source metadata fields.

## Source Rights Review

Before final public DOI publication, source redistribution rights should be
reviewed carefully. Public TamilVU pages checked during release preparation state
that the website is designed, developed, and maintained by Tamil Virtual Academy
and display copyright attribution to Tamil Virtual Academy. I did not find an
explicit open-content license granting unrestricted redistribution of source text.

Because of this, the release follows a conservative model:

- The project code, schemas, release metadata, audit reports, and documentation
  are licensed under the repository license unless otherwise stated.
- TamilVU-derived source text is attributed to Tamil Virtual Academy/TamilVU and
  may be subject to separate rights.
- Users must preserve source attribution and source URLs.
- Users should verify whether their intended reuse of TamilVU-derived text is
  permitted.
- If full-text redistribution permission is not confirmed before Zenodo
  publication, publish either a restricted-file Zenodo record or an open
  metadata/schema/checksum/sample package and keep full-text reconstruction
  instructions in the public repository.
