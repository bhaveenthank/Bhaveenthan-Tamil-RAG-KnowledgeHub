# Retrieval Project

Owns retrieval-ready enrichment, chunking, lexical indexes, occurrence search, embeddings, vector indexes, and RAG context packaging.

## Inputs

- normalized corpus records
- optional annotation artifacts
- retrieval/evaluation manifests

## Outputs

- enriched records
- retrieval chunks
- lexical and occurrence indexes
- embeddings and vector indexes
- RAG context packages

Retrieval outputs are derived artifacts and should preserve citation paths to normalized/source records.
